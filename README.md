# Lakshay Bansal — Ultimate Reactive Portfolio

A high-performance, ultra-responsive **Personal Portfolio & Software Engineer Showcase** built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

![Portfolio Preview](public/profile.jpg)

---

## ✨ Features

- **⚡ Reactive Theme Engine**: Real-time CSS variable accent customization (*Amber, Cyber Cyan, Emerald Green, Electric Violet, Neon Rose, Sky Blue*) with an interactive particle physics background canvas.
- **🖼️ Cinematic Hero & Floating 3D Tech Orbit**: High-impact portrait layout with floating, animated 3D tech badges (`TS`, `JS`, `Node.js`, `React.js`, `MongoDB Leaf`).
- **🎯 Section 01 (PROFILE)**: Giant display typography (`FULL STACK DEVELOPER.`), status pill (`AVAILABLE FOR WORK`), and embedded configuration info terminal window.
- **📂 Dynamic Project Showcase**: Category filterable project gallery with detailed architecture quick-view modal.
- **📄 Interactive Digital Resume Viewer**: Complete digital rendering of Lakshay Bansal's official resume with PDF download and print capabilities.
- **💬 Contact Section**: Stroked outline typography (`START A PROJECT`), email action pills, copy to clipboard tool, and real-time form validation.
- **🏁 Footer Bar**: Status beacon (`AVAILABLE — FREELANCE & FULL-TIME`), uppercase mono links, and copyright notices.

## 🚀 Getting Started

### Prerequisites

- Node.js v18+ and npm installed

### Installation

```bash
# Clone the repository
git clone https://github.com/lakshay637/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser to view the application live.

### Building for Production

```bash
npm run build
```

The optimized production bundle will be generated in the `dist/` directory.
